# Windows programs (Wine, Proton, Bottles): missing parts they need to start

id: win-0xc000007b
match: 0xc000007b
match: application was unable to start correctly \(0x0*c000007b\)
level: green
title: A Windows program could not start
say: This Windows program is missing a part it needs to start, or a part of the wrong kind (32-bit or 64-bit) got mixed in.
do: Your files are fine. Open Will It Run? to check this program and the best way to run it on ForgeOS.
fix: open:willitrun
example: The application was unable to start correctly (0xc000007b). Click OK to close the application.

id: win-vcruntime
match: (msvcp|vcruntime)14\d(_\d)?\.dll
match: api-ms-win-crt-[a-z-]+l1-1-0\.dll
level: green
title: A Windows program is missing a helper part
say: This Windows program needs a free helper package from Microsoft (Visual C++ 2015-2022) that is not set up for it yet.
do: Nothing is broken. Open Will It Run? to check the program; running it through Steam or Bottles usually adds the part by itself.
fix: open:willitrun
example: The code execution cannot proceed because MSVCP140.dll was not found. Reinstalling the program may fix this problem.
example: The program can't start because VCRUNTIME140_1.dll is missing from your computer.
example: api-ms-win-crt-runtime-l1-1-0.dll is missing
