# Undo Button
words: undo deleted file get back older version restore snapshot
Undo Button keeps copies of your home folder every hour, so you can get back a deleted or changed file.
- Right-click a file or folder in Dolphin and pick Get back an older version, or open Undo Button from the menu.
- A file you get back is saved as a new copy; nothing is overwritten.
- It can also go back to the last system version if an update caused a problem.
