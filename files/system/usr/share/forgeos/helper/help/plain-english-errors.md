# Plain-English Errors: what an error message means and what to do
words: error message code meaning explain warning crash closed unexpectedly not responding failed what went wrong 0x dll
When something goes wrong, ForgeOS tells you in plain English. Each card says: what happened, how serious it is (not serious, needs a look, or serious), and what to do, with one Fix it button.
- Press Meta+Shift+E to explain the error on your screen. Or copy the error's words (select them, Ctrl+C), then press Meta+Shift+E.
- Error pop-ups get a "What does this mean?" button. Programs that close by themselves get a card too.
- Open "What Went Wrong" from the menu to see the last 30 days, in plain English. It is kept only on this PC.
- Fix it only does things from a short checked list, and only when you click it.
- Real errors never show a phone number and never ask for money. A "virus" warning with a number to call is a scam: close it and call no one.
- You can also ask Forge Helper: "what does this error mean?" and paste the words.
