# Windows and ForgeOS on one PC
words: windows 11 dual boot switch restart boot start-up menu forgeos both systems
If Windows 11 is on this PC too, you can switch any time and your files stay where they are.
- In ForgeOS: click "Restart into Windows" (desktop icon, or the "Windows & ForgeOS" window in the menu). Save your work first.
- In Windows: double-click "Restart into ForgeOS" on the desktop and say Yes when Windows asks.
- Or pick the system in the start-up menu while the PC starts.
- After a switch, the next normal start-up is ForgeOS again.
- The Windows button is set up from the "Windows & ForgeOS" window (your PC password is needed).
