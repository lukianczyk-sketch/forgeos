# Ask Before Connecting: which programs may use the internet
words: internet firewall block allow app program connect connection online who uses lock down opensnitch stopped working can't connect
The first time a program tries to use the internet, ForgeOS asks you: Allow, Block, or Just this once. Your answer is remembered.
- ForgeOS's own programs, the apps it installs and Steam games are never asked.
- Not sure? Press Block. "What is this?" lets the private AI say what the program is. It never decides for you.
- No answer in 30 seconds = blocked for now. In a game you get one short list afterwards.
- A program in Downloads, a temp or a hidden folder gets a red warning every time.
- Scam websites are blocked by themselves. A remote-control app asks if a stranger told you to install it.
- "Who Uses the Internet" in the menu: change any answer, see today's list, "Something stopped working?" and Lock down (blocks every NEW program, for travel and public Wi-Fi).
