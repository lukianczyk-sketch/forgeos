# Will It Run?
words: will it run windows program exe game install compatible
Will It Run? tells you if a program or game will work on ForgeOS and the best way to run it.
- Right-click the downloaded file in Dolphin and pick Will it run on ForgeOS?, or open it from the menu and type the program name.
- It checks the file for viruses and never runs it. It may suggest a free program that does the same job.
