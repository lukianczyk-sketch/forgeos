# Why Is It Slow?: find out why the PC is slow and fix it
words: slow sluggish lag laggy faster speed up memory ram full hot startup frozen task manager internet
Open "Why Is It Slow?" from the menu (or ask Forge Helper "why is my computer slow"). In about 15 seconds it checks everything and answers in plain English, worst problem first.
- Each problem has a fix button that asks first: close a busy program, switch off power saver, free up space, choose what starts with the PC, restart.
- It also tells you when it is the internet, not the PC (weak Wi-Fi, a poor router, or your internet company).
- "It was slow a few minutes ago": it keeps a tiny 7-day history on this PC, so it can still say what happened.
- It never closes a program or deletes a file without your Yes, and it never turns off security to "speed up".
